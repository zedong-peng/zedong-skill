name: zedong-quant-note
description: How the user records a trading strategy, paper, post or experiment in their quant research repo. Use when writing such a note.
---

The repo sets the form: read its README, `CLAUDE.md` or `AGENTS.md`, state file and a few recent notes, and match their language (often Chinese), headings, tone, file naming and commit style. If there is a survey or index table, add one row.

Check first whether an existing experiment or note already covers the idea; if so, say so and link it rather than duplicating the work.

Judge the claim before recording it:

- Where does it really come from? Trace the original author and code.
- Is the backtest out of sample, and are costs modeled?
- What are the actual Sharpe and drawdown, over which universe and period?

A dubious source becomes a short warning note: what it claims, what it really is, why it is not worth pursuing. Not a strategy entry.

End with the link and a one-line verdict.

# Visual reference

Saved for future reference: [Anthropic brand guidelines](https://github.com/anthropics/skills/blob/main/skills/brand-guidelines/SKILL.md).

Use that page as a reference when a user requests Anthropic-like styling. The bundled template borrows the warm light background, dark text and terracotta accents. It keeps **Georgia for the cover title and overview headings, and system fonts for other text**. Changing the palette does not automatically change the fonts.

## Template palette

| Element | Colour |
| --- | --- |
| Cover background | `#faf9f5` |
| Figure-slide background | `#ffffff` |
| Main text and presentation surround | `#141413` |
| Source notes | `#6b6962` |
| Active chapter text | `#a6533c` |
| Active progress bar | `#d97757` |
| Completed progress bars | `#b0aea5` |
| Subtle lines and empty progress bars | `#e8e6dc` |

These are the template's choices, not a complete reproduction of that brand guide. Preserve the colours and backgrounds inside source figures. If custom fonts are requested, package their font files and required license notices inside the HTML so forwarding the single file still works offline.

name: zedong-think
description: How the user thinks through a direction, and their research taste. Use when choosing or assessing a direction, plan, technical approach or experiment, in research, engineering or anything else.
---

Before judging a direction or plan, step back. Does the problem itself have taste? Is the goal big enough? Is there a bigger solution that makes the problem disappear? If it isn't worth doing, say so plainly and recommend not doing it. Prefer questions grounded in a concrete bottleneck and approaches derived from the underlying problem.

The user's reference for research is Anthropic's: taste in the question chosen and technical depth in the evidence for it.

For LLM research, the user values methods that address current models' pain points. Small local models can establish a direction through gains over their own baselines and a credible case for scaling; beating frontier models on absolute score is not the aim.

Value elapsed time to a useful conclusion when choosing experiments. Before running one, sketch the results table it should fill. Before a long build or training run, make sure the change can actually fix the problem; a long run is not a way to try your luck.
